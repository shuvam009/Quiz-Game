# 🎯 Quiz Game

A simple and interactive Quiz Game built using **HTML, CSS, and JavaScript**. This project demonstrates core JavaScript concepts like DOM Manipulation, Event Listeners, Dynamic Element Creation, and basic game logic.

## 🚀 Features

- 📚 Multiple-choice quiz
- 🎨 Clean and responsive UI
- 📊 Live score tracking
- 📈 Progress bar
- ✅ Correct & Incorrect answer highlighting
- 🔄 Restart quiz functionality

## 🎮 How to Play

1. Click the **Start Quiz** button.
2. Read the question carefully.
3. Select the correct answer.
4. Your score updates automatically.
5. After the final question, your score and performance message are displayed.
6. Click **Restart Quiz** to play again.
